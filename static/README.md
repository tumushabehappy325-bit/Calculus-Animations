# Calculus Animations with Python

This project demonstrates how to visualize calculus concepts using Python.

##  Features
- Animated visualization of functions
- Tangent line animation (derivatives)
- Static plots showing:
  - Function graph
  - Derivative graph
  - Critical points
  - Increasing/decreasing intervals

##  Example Function
g(x) = x^2 + 16/x^2

##  Project Structure
animations/   -> animation scripts 
static/       -> static visualizations 
outputs/      -> generated images/videos 

## installation
pip install -r requirements.txt

## Run

Animation:
python3 animations/animate_g.py

Static:
python3 static/static_g.py

## Output
- GIF animations
- MP4 videos
- PNG images
